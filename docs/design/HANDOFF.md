# Передача разработчику — графический комплект «Морошка»

## Точка входа

1. Откройте `index.html`: это локальный каталог изображений и ссылок на компоненты. Для полного просмотра достаточно браузера; доступ к внешним сервисам не требуется.
2. Сверьте художественное направление с `mockups/04-asset-board.png` и `05-approved-reference.png`.
3. Прочитайте `SPEC.md`: согласованное поведение и простая навигация имеют приоритет над ранними декоративными концептами.
4. Проверьте `ASSET_COVERAGE.md` и `manifest.json`: у каждого обязательного элемента есть путь и происхождение.

## Какие файлы подключать

| Задача | Ресурсы |
| --- | --- |
| Объёмная морошка без фона | `assets/raster/brand/cloudberry-3d.png` |
| Декоративная веточка | `assets/raster/brand/cloudberry-sprig.png` |
| Иконка приложения | `assets/raster/brand/app-icon-3d.png`, варианты `app-icon-48.png` … `app-icon-512.png` |
| Монохромный знак и логотип | `assets/brand/` |
| Интерфейсные пиктограммы | `assets/icons/` — SVG с `currentColor`; PNG-экспорты в `assets/icons-png/` |
| Детализированные фоны | `assets/raster/backgrounds/` — отдельные широкие и портретные композиции, WebP и JPEG |
| Тематические изображения | `assets/raster/illustrations/` — WebP; полноразмерные PNG-мастера в `assets/masters/illustrations/` |
| Кнопки, поля, карточки, теги, переключатели | `assets/components/` и `assets/effects/` |
| Типографика | `assets/fonts/Manrope-Variable.ttf`, обязательно сохранять `OFL.txt` |

Пейзажи занимают компактную область шапки или обложку. Длинный текст размещается на спокойной поверхности. Не включайте все иллюстрации в каждый экран. Используйте портретную композицию для высокого фона, широкую — для обложки; не растягивайте изображение с нарушением пропорций.

## Соответствие продукту

Сохранить утверждённые подписи: «Морошка», «О чём вы думаете?», «Голос», «Сохранить», «Недавние», «Все заметки», «Главная», «Поиск», «Связи», «Библиотека». Не добавлять обязательный выбор «Заметка / Задача / Проект / Идея» перед вводом. Содержание примеров с планшета не импортировать в пользовательскую базу.

Сначала сохранить заметку; затем запускать разрешённую интеллектуальную обработку. Исходный текст и ручные изменения не перезаписывать. Предложения заголовков, тегов и связей показывать отдельно. Смысловые связи строить из реальных данных; декоративная нейросеть из набора не заменяет рабочий граф.

## Android

Использовать существующие Kotlin/Android SDK-компоненты и хранилище проекта. WebP/PNG можно импортировать в соответствующие Android resources после проверки размеров и потребления памяти. SVG-иконки следует преобразовать в VectorDrawable средствами Android Studio; `currentColor` заменить на цвет темы. CSS напрямую в нативном Android не исполняется: перенести значения токенов и поведение в платформенные компоненты.

Полноразмерные PNG в `masters/` предназначены для дальнейшего экспорта; не включать их все в APK. Квадратные PNG иконки не являются готовым adaptive icon. Для adaptive icon используйте отдельный прозрачный знак и отдельный фон, проверьте маски и безопасную зону. Не менять AndroidManifest автоматически только ради демонстрации ресурса.

## Веб

Подключить локальный шрифт через `@font-face`, эффекты и компоненты — через CSS. Для декоративных изображений использовать `alt=""`, для значимых — краткое описание. Интерактивные иконки должны быть внутри кнопки с доступным названием. `currentColor` удобно использовать inline или через CSS mask; обычный `<img>` не наследует цвет SVG из текста родителя.

## Состояния и качество

Проверить фокус с клавиатуры, disabled/loading/error, светлую и тёмную темы, крупный шрифт и экранный диктор. Эффекты не должны задерживать ввод или скрывать статус сохранения. Поддержать `prefers-reduced-motion`; на Android учитывать системные настройки анимации. Область нажатия — не менее 48 dp по спецификации проекта.

Контраст проверять на фактической подложке, включая градиенты и изображения. Яркий оранжевый и светлое свечение — декоративные акценты; для мелкого белого текста подходят только проверенные тёмные участки. Реальный экран проверяется после интеграции, а не по одному набору токенов.

## Проверка перед интеграцией

```bash
python3 docs/design/tools/validate_assets.py
```

Для повторного экспорта изображений из сохранённых PNG-мастеров (нужен Pillow):

```bash
python3 docs/design/tools/export_assets.py
```

Не регенерировать изображения без необходимости: каждый мастер уже включён в репозиторий. Проверить итоговые UI на устройстве и запускать существующие тесты приложения при изменении исходного кода.

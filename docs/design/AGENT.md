# Задание агенту-разработчику
Внедри дизайн «Морошка 2.1» в существующее приложение. Изучи репозиторий, стек, маршруты, компоненты, хранилище, API, тесты и текущие изменения. Не переписывай проект с нуля. Работай в отдельной ветке, не уничтожай незакоммиченные изменения. Используй SPEC.md как источник поведения, tokens.json как стартовую систему стилей, mockups как визуальные ориентиры, prototype.html как пример сценариев. Не копируй вымышленные данные. Переиспользуй текущие сервисы и компоненты; недостающие возможности явно обозначь и реализуй отдельно только при наличии подходящей архитектуры. Сначала токены и общие компоненты, затем главный экран, заметка, поиск, библиотека, связи, состояния ошибок. Проверь контраст и доступность. Запусти существующие тесты и сборку, добавь проверки сценариев из SPEC.md. Представь список изменений, скриншоты реального приложения и ограничения. Не публикуй в production без отдельного согласования.

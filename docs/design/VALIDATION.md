# Проверка комплекта 2.2

## Проверено в этой передаче

- Пять оригинальных изображений совпадают с восстановленными источниками по SHA-256.
- Все 18 PNG-мастеров и их экспортные варианты декодируются.
- Фоны имеют экспортные размеры 1600×900 и 900×1600; кадрирование не растягивает пропорции. Прямоугольники находятся в пределах исходников. Экспорты сравнивались с соответствующими областями мастеров с учётом сжатия.
- Прозрачные морошка и веточка содержат альфа-канал с диапазоном 0–255.
- Все 27 позиций пиктограмм планшета присутствуют; всего в наборе 37 SVG и 37 PNG 96×96. SVG валидны как XML, PNG-пиктограммы имеют отступы от границ.
- Manrope содержит русскую кириллицу и variable-ось; оригинальная OFL 1.1 приложена.
- Редактируемый SVG UI kit и словесный логотип отрендерены с Manrope и просмотрены: наложений и обрезаний текста не обнаружено.
- JavaScript примеров проверен на синтаксис. В HTML компонентов нет повторяющихся идентификаторов; основная навигация состоит из четырёх пунктов.
- Проверены локальные ссылки, наличие заявленных файлов и контрольные суммы полного комплекта.
- Android-шаблоны прошли разбор XML, проверку ссылок на ресурсы и расчёт безопасной области знака. Подробности и допустимый прозрачный шум исходной генерации описаны в `assets/platform/android/README.md`.

## Пределы проверки

Полноценный браузерный прогон взаимодействий и запуск на Android-устройстве здесь не выполнены: Chromium не запустился из-за ограничений среды. Они не выдаются за пройденные. SVG-превью проверено отдельно. Комплект не объявляется полной WCAG-сертификацией готового приложения.

Исходный код приложения не меняется этой передачей. Проверка сборки Android и серверных тестов требуется при фактическом внедрении дизайна; документация и графика сами по себе не подтверждают его внедрение.

## Повторить проверку

Требуются Python 3, Pillow и fontTools:

```bash
python3 docs/design/tools/validate_assets.py
python3 docs/design/assets/platform/android/verify_template.py
```

При намеренном обновлении ресурсов сначала восстановить нужные экспортные варианты и каталог, затем пересоздать манифест:

```bash
python3 docs/design/tools/export_assets.py
python3 docs/design/tools/build_catalog.py
python3 docs/design/tools/build_manifest.py
python3 docs/design/tools/validate_assets.py
```

Не пересоздавать манифест, чтобы скрыть повреждение или недостающий файл: сначала свериться с исходниками и картой покрытия. `manifest.json` исключает себя и `CHECKSUMS.sha256` из собственного списка; checksum-файл дополнительно покрывает сам манифест.

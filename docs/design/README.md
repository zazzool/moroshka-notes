# Морошка — Design System 2.1
Пакет передачи дизайна. Изображения — концепты, не пиксельно точные спецификации. При конфликте приоритет у SPEC.md и сохранения существующих функций. Не переносить демонстрационные медицинские тексты, имена, счётчики и проценты в реальные данные.

- mockups/01.png — первоначальный концепт
- mockups/02.png — гибридная концепция
- mockups/03.png — визуальная полировка
- SPEC.md — интерфейс и поведение
- tokens.json — предлагаемые дизайн-токены
- prototype.html — автономный интерактивный пример (открыть браузером)
- AGENT.md — задание агенту

Прототип не подключён к серверу, ИИ или микрофону. Токены — нормативное предложение, не извлечённые из изображений значения.

# Морошка — комплект дизайна 2.2

Полная передача согласованной концепции 2.1: оригинальные макеты, отдельная художественная графика, пиктограммы, редактируемые компоненты и инструкция для внедрения в существующее приложение.

**Начните с [визуального каталога](index.html), [карты покрытия](ASSET_COVERAGE.md) и [инструкции разработчику](HANDOFF.md).** GitHub показывает исходный HTML; для просмотра каталога откройте локальную копию в браузере.

## Состав

| Путь | Содержимое |
| --- | --- |
| `mockups/` | Три оригинальных концепта, исходный планшет и версия пользователя; сохранены побайтно |
| `assets/masters/` | 18 новых полноразмерных PNG: десять фонов, пять иллюстраций, три изображения бренда |
| `assets/raster/` | WebP/JPEG для приложения, прозрачные PNG и варианты размеров иконки |
| `assets/icons/` | 37 SVG: все 27 позиций планшета и десять дополнительных пиктограмм прежнего прототипа |
| `assets/icons-png/` | 37 PNG-версий интерфейсных пиктограмм |
| `assets/brand/` | Векторные знаки и словесные логотипы |
| `assets/components/` | Редактируемый SVG-набор, его PNG-превью и интерактивный HTML-пример |
| `assets/effects/` | Градиенты, свечение, поверхности, состояния и движение |
| `assets/fonts/` | Manrope Variable с кириллицей и оригинальной лицензией |
| `assets/platform/android/` | Шаблоны ресурсов для адаптивной иконки Android |
| `assets/generation.json` | Промпты и происхождение всех новых художественных ресурсов |
| `manifest.json`, `CHECKSUMS.sha256` | Полный перечень файлов, размеры и контрольные суммы |
| `tools/` | Воспроизводимый экспорт и проверка целостности |

## Приоритет решений

1. Требования пользователя и сохранение существующих функций приложения.
2. [SPEC.md](SPEC.md): поведение, единое поле ввода и четыре пункта навигации.
3. [HANDOFF.md](HANDOFF.md): правила подключения ресурсов.
4. Компоненты, токены и макеты: визуальные ориентиры.

Демонстрационные медицинские тексты, вымышленные счётчики, проценты и обещания функций из концептов не переносить в реальные данные. Рабочий граф строится по реальным связям между материалами.

## Точность и происхождение

Исходные макеты сохранены точно. Новые самостоятельные растровые ресурсы **воссозданы по референсу**: исходный планшет не содержит отдельных слоёв. Пиксельная идентичность его миниатюрам не заявляется. Старые упрощённые SVG-фоны оставлены для совместимости; для основного художественного оформления используйте новые `assets/raster/`.

Набор компонентов поставляется в SVG и HTML/CSS. SVG можно импортировать в Figma; нативная `.fig`-библиотека не заявляется. Происхождение и первичные источники: [SOURCES.md](SOURCES.md).

## Просмотр и проверка

Откройте `index.html` в браузере. Если браузер ограничивает локальные шрифты, запустите из корня репозитория `python3 -m http.server 8000` и откройте `http://localhost:8000/docs/design/index.html`.

Проверка пакета:

```bash
python3 docs/design/tools/validate_assets.py
```

`prototype.html` — сохранённый демонстрационный прототип предыдущего этапа. Его данные живут в памяти страницы; микрофон и ИИ к нему не подключены. Этот комплект передаёт дизайн и ресурсы; внедрение и проверка приложения выполняются в его кодовой базе.

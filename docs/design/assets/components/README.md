# Компоненты и редактируемые векторы

## Состав

- **showcase.html** — автономная галерея с переключением темы, состояниями полей, кнопок, тегов, переключателей, ползунка, голосовой анимации и навигации. Откройте файл браузером; CSS находится в ../effects/components.css. Данные приложения, сервер, ИИ и микрофон не используются. Изменения примеров не сохраняются между загрузками.
- **ui-kit.svg** — редактируемые формы, иконки и живой текст на одном планшете. Откройте в Figma, Inkscape или другом SVG-редакторе. Это SVG для импорта, а не нативный .fig. Figma Auto Layout, Component Variants и привязки к токенам необходимо настроить после импорта. Копирование формы в Figma само по себе не создает интерактивный компонент.
- **ui-kit-preview.png** — растровый просмотр того же планшета.
- **icons-sprite.svg** — набор SVG symbols с идентификаторами i-home, i-search и т. д.; он не предназначен для отображения как отдельная картинка.
- **../icons-coverage.json** — отображение всех 27 позиций иконок исходного планшета на файлы. В ../icons/ всего 37 SVG: 20 существующих и 17 добавленных. Две прежние геометрии (link, layers) исправлены для безопасных отступов.
- **../icons-png/** — прозрачные PNG всех 37 иконок, 96×96 px, сливовый цвет #48374E.
- **../brand/cloudberry-mono-orange.svg**, **cloudberry-mono-plum.svg**, **wordmark-orange.svg**, **wordmark-plum.svg** — прозрачные векторные варианты марки и надписи.

## Шрифты и импорт

Галерея загружает локальный ../fonts/Manrope-Variable.ttf; сетевое подключение не требуется. Лицензия шрифта находится в ../fonts/OFL.txt. Для редактирования текста SVG установите этот шрифт в используемой системе или выберите подходящий fallback. Для неизменного внешнего вида при печати можно перевести надпись в контуры. Файлы SVG сохраняют текст редактируемым.

## Принципы интеграции

Приоритет сценариев и подписей — ../../SPEC.md. Навигация содержит «Главная», «Поиск», «Связи», «Библиотека». Пять пунктов на раннем художественном изображении не являются актуальной навигационной спецификацией.

Иконки перерисованы по назначению и общему контуру; они не извлечены из растрового планшета и не являются оригинальными скрытыми векторами. Новые SVG используют текущую толщину набора 1.8 px, скругленные концы и currentColor. Для веба вставьте inline SVG и задайте color на родителе; цвет страницы не наследуется внутрь внешнего img. Для Android преобразуйте геометрию в VectorDrawable или примените PNG, задавая tint в коде.

Видимая иконка 24×24 размещается в отдельной сенсорной области минимум 48×48 dp. Компактные теги на SVG-планшете показывают видимую форму; их реальная область нажатия должна быть расширена. В HTML интерактивные теги уже имеют высоту 48 px. Градиенты, свечение и декоративный фон не должны снижать читаемость текста; используйте контрастную поверхность.

CSS включает явные focus-visible, disabled, aria-invalid и prefers-reduced-motion. Это примеры компонентов, а не подтверждение доступности всего приложения. Белый текст основной кнопки размещен на градиенте #B84F3B → #794298; светлый оранжевый оставлен для декоративного свечения.

Галерея ссылается на ../raster/backgrounds/cloudberry-landscape-landscape.webp как декоративный баннер. Если изображение отключено, фон остается градиентным; критичные действия от него не зависят. Схематический граф в библиотеке компонентов — пример стиля узлов и ребер; в приложении он строится только по реальным данным.

## Первичные справочные материалы

- SVG 2: viewBox и преобразования — https://www.w3.org/TR/SVG/coords.html
- SVG 2: цвет и currentColor — https://www.w3.org/TR/SVG/painting.html
- Android: размеры областей нажатия и доступность — https://developer.android.com/guide/topics/ui/accessibility/apps
- Lucide: организация SVG-иконок и импорт в Figma — https://lucide.dev/contribute/icons/figma-guide

Эти источники использованы как технические ориентиры. SVG-геометрия дополнения создана для пакета, исходные иконки Lucide в него не копировались.

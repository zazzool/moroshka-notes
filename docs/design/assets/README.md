# Moroshka UI Asset Pack 2.1
Самостоятельные оригинальные SVG-ресурсы: бренд, контурные иконки 24×24, стилизованные пейзажи 16:9, тематические иллюстрации и CSS-токены. Это векторная интерпретация концепции, не извлечённые растровые изображения из исходных макетов. Иконки используют currentColor; при нативном импорте задайте цвет средствами платформы. Фоны декоративные, текст размещать на контрастной подложке. Не заменять существующие ресурсы без проверки. Оригинальные PNG-макеты в этот набор не включены.

# Moroshka UI Asset Pack 2.2

Ранее переданный векторный набор дополнен детализированной растровой графикой и редактируемыми компонентами. Откройте [визуальный каталог](../index.html) и [карту соответствия](../ASSET_COVERAGE.md).

- `masters/`: 18 нетронутых исходных PNG новых генераций.
- `raster/`: WebP/JPEG, прозрачные PNG и размеры иконки приложения. Фоны экспортированы точно в 1600×900 и 900×1600 с сохранением пропорций; техническое кадрирование записано в `raster/export-map.json`.
- `icons/`: 37 SVG, включая все 27 позиций планшета. Цвет задаётся через `currentColor`; в native-импорте требуется цвет платформы.
- `icons-png/`: 37 переносимых PNG-версий пиктограмм.
- `brand/`: векторные знаки и логотипы. Детализированная морошка находится в `raster/brand/`.
- `components/`, `effects/`: компоненты, состояния, эффекты и редактируемый SVG.
- `fonts/`: Manrope Variable и лицензия OFL.
- `platform/android/`: шаблоны Android-ресурсов, а не автоматически внесённые изменения приложения.

`backgrounds/*.svg` и `illustrations/*.svg` — ранние упрощённые ресурсы. Они сохранены ради существующих ссылок; новые художественные изображения подключаются из `raster/`.

На пейзажах не размещать длинный текст без контрастной поверхности. Для декоративных изображений использовать пустой alt; кнопкам с пиктограммами задавать доступное название. Изображение нейронной сети не заменяет рабочий интерактивный граф.

Источники: [SOURCES.md](../SOURCES.md). Новые изображения воссозданы по референсу; оригинальные макеты находятся в `../mockups/`.

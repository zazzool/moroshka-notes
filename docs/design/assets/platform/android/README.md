# Android launcher icon — шаблон для интеграции

Шаблон ресурсов «Морошки». Он находится в дизайн-пакете и ещё не подключён к `android/app/`. Все имена начинаются с `moroshka_`.

## Что включено

- `res/mipmap-anydpi-v26/moroshka_launcher.xml`: адаптивная иконка с отдельными фоном и передним планом.
- `res/mipmap-anydpi-v33/moroshka_launcher.xml`: та же иконка с монохромным слоем для тематических значков.
- `res/drawable-v26/moroshka_launcher_foreground.xml`: масштабируемые относительные отступы и фильтруемый PNG.
- `res/drawable-nodpi/moroshka_launcher_foreground_art.png`: точная, неретушированная копия `brand/cloudberry-3d.png`, с настоящим alpha-каналом.
- `res/drawable/moroshka_launcher_background.xml`: непрозрачный градиент на всю площадь слоя, без скруглений.
- `res/drawable/moroshka_launcher_monochrome.xml`: прозрачный одноцветный VectorDrawable; геометрия основана на `brand/cloudberry-mono-plum.svg`.
- `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/moroshka_launcher.png`: обычные PNG 48, 72, 96, 144 и 192 px, экспортированные из `brand/app-icon-3d.png` только уменьшением размера.

## Подключение

После проверки перенести содержимое `res/` в каталог ресурсов приложения с сохранением квалификаторов. Изменить существующий атрибут `android:icon` элемента `<application>` в `AndroidManifest.xml`:

```xml
android:icon="@mipmap/moroshka_launcher"
```

Если приложение уже использует `android:roundIcon`, можно направить его на тот же ресурс, предварительно проверив круговую маску:

```xml
android:roundIcon="@mipmap/moroshka_launcher"
```

API 26–32 выберут адаптивный ресурс `v26`, API 33+ — вариант `v33`; более ранние версии получат PNG по плотности. Для компиляции XML с `<monochrome>` нужен `compileSdk` не ниже 33. Это не требует увеличения `minSdk` до 33.

## Геометрия и прозрачность

Расчётная площадь слоя — 108 × 108 dp, проверочный круг в центре — диаметром 66 dp. Передний план использует одинаковые относительные отступы 15,75%: на расчётной площади это 17,01 dp с каждой стороны, приблизительно 74 × 74 dp для исходного квадратного PNG. Относительные отступы сохраняют пропорции при изменении границ drawable; фактическое округление пикселей выполняет Android.

Непосредственно по alpha-каналу исходного PNG проверены пиксели с **alpha ≥ 2 из 255**. Их максимальное расстояние от центра при консервативном размере квадрата 74 dp — менее 33 dp, включая половину диагонали пикселя. Видимая область знака занимает около 56 × 53 dp. Точные результаты и SHA-256 приведены в `validation.json`.

Исходник содержит разрознённые почти прозрачные пиксели **alpha = 1** за пределами основной фигуры. Они сохранены без ретуши; геометрическая гарантия круга относится к alpha ≥ 2. Нельзя утверждать, что все ненулевые пиксели исходника помещаются в проверочный круг. Эти слабые пиксели могут быть отсечены маской лаунчера.

Для монохромной геометрии применён строгий верхний предел: выпуклая оболочка контрольных точек кривых, окружности и половина толщины скруглённой обводки после масштабирования полностью лежат внутри проверочного круга. Предел не зависит от прозрачности PNG.

## Проверка перед интеграцией

Запустить из этого каталога:

```sh
python3 verify_template.py
```

Нужен Python с Pillow. Проверка разбирает XML, разрешает локальные ссылки на ресурсы, проверяет размеры PNG, рассчитывает safe-zone и сверяет байты переднего плана с сохранённым SHA-256. Она не заменяет сборку Android.

Перед выпуском открыть ресурсы в Android Studio, проверить круг, скруглённый квадрат и другие маски, разные плотности, обычную и тематическую иконку в поддерживающем лаунчере. Запустить сборку проекта и проверку на устройстве. **В рамках подготовки этого шаблона Android-сборка и проверка на устройстве не выполнялись.** Отдельный квадратный `app-icon-3d.png` не является адаптивной иконкой: адаптивное поведение обеспечивают XML и слои.

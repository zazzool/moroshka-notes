# Интеграция утверждённой графики

## Android
Нативные компоненты Kotlin/Views используют Manrope, реальные растровые фоны, исходный 3D-знак, адаптивную иконку (API 26, монохромная с API 33), тематические пустые состояния, цветные карточки и градиентный граф реальных заметок. На открытой клавиатуре компактная обложка и навигация скрываются. Список связей сохранён как доступная альтернатива графу.

## Web
Общая палитра, Manrope, локальные изображения и пиктограммы, светлая/тёмная темы, новый блок быстрого захвата с локальным черновиком и сохранением в существующее Markdown-хранилище. Существующие списки, редактор, импорт, экспорт, синхронизация, задачи и OpenRouter сохраняются. Сервер отдаёт только явно разрешённые статические ресурсы, service worker включает их в офлайн-оболочку.

## Ресурсы
`ANDROID_RUNTIME_ASSETS.json` и `WEB_RUNTIME_ASSETS.json` связывают оптимизированные runtime-копии с утверждёнными оригиналами. Проверка хешей входит в `node --test tests/*.test.mjs`. Не переносить полноразмерные мастер-файлы в APK и Docker. Не подменять реальный граф декоративным изображением и не показывать фиктивные ИИ-рекомендации. ИИ-классификация, полноценная запись аудио и структурированные проекты остаются отдельными функциональными задачами.

## Приёмка
- `node --test tests/*.test.mjs`
- `CHROMIUM=/usr/bin/chromium python3 tests/browser.py`
- `cd android && ./gradlew :app:assembleDebug :app:assembleDebugAndroidTest`
- Запуск SmokeRunner на чистом эмуляторе, затем ручная проверка 320/360 dp, крупного шрифта, клавиатуры, TalkBack, светлой/тёмной тем и масок лаунчера.
- Проверить установку поверх предыдущего debug APK, не удаляя данные.
- После прохождения проверок — отдельное решение о выпуске. Скриншоты и результаты сборки должны быть сняты с реального клиента, не с макета.

# От записной книжки к базе знаний

Первая версия поддерживает цикл «записать → связать → найти → вернуться к задаче». Файл служит переносимой единицей знания. Список задач и обратные ссылки вычисляются из текста.

| Наблюдение по документации продуктов | Решение Moroshka Notes |
| --- | --- |
| Obsidian Bases собирает таблицы и карточки поверх свойств локальных Markdown-файлов. [Obsidian Bases](https://help.obsidian.md/bases) | Сохранять заметки как обычный Markdown. Использовать вики-ссылки для переходов и обратных ссылок. |
| В Notion несколько представлений и фильтров работают с общими записями. [Notion Database Views](https://www.notion.com/help/views-filters-and-sorts) | Первый пример — общий список задач. Переключение чекбокса меняет строку той же заметки. |
| Joplin поддерживает несколько целей синхронизации и отделяет интерфейс приложения от серверного хранилища. [Joplin Synchronisation](https://joplinapp.org/help/apps/sync/) | Хранить правки на устройстве, передавать их на сервер владельца через небольшой HTTP API, сохранять конфликтные версии. |
| Amnezia устанавливает сервис на VPS владельца через SSH. [Инструкция Amnezia](https://docs.amnezia.org/documentation/instructions/install-vpn-on-server/) | Упаковать исходники и установщик в один файл. Запрашивать у владельца адрес сервера, домен и данные SSH. |
| OpenRouter принимает сообщения с выбранным идентификатором модели. ChatGPT поддерживает Actions с авторизацией API key. [OpenRouter](https://openrouter.ai/docs/api-reference/chat-completion) · [GPT Actions](https://developers.openai.com/api/docs/actions/authentication) | Отправлять выбранную заметку в OpenRouter по отдельному действию. Дать личному GPT два инструмента с отдельным ключом чтения. |

## Порядок развития

1. **Надёжность личного архива.** История правок, корзина с синхронизацией удаления, полный импорт и экспорт каталога, автоматизированная проверка восстановления резервной копии. Добавить инкрементальный обмен для больших библиотек.
2. **Структурированные коллекции.** Сохранённые фильтры, свойства в YAML frontmatter, табличное представление и доски. Подобрать поддерживаемый парсер с совместимой лицензией, проверить обратную запись на реальных файлах.
3. **Навигация по знаниям.** Карта соседних заметок, обработка переименований, более точное различение ссылок, кода и цитат полноценным Markdown-парсером.
4. **Клиенты и интеграции.** Доработать фоновый обмен на Android, добавить выбор папки и ограничение контекста для AI. Для подключения через каталог приложений ChatGPT спроектировать авторизацию по пользователю и MCP-сервер.

Для Android используем Kotlin и Android SDK, для сервера — стандартную библиотеку Node.js, для веба — API браузера. Gradle и Kotlin остаются в сборочной цепочке. HTTPS и управление сертификатами поручены Caddy. Следующую библиотеку стоит добавлять под конкретную проверяемую функцию с учётом её лицензии, размера и стоимости сопровождения.
